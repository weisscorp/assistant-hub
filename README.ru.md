# Assistant Hub

Локальный хаб личного ассистента: общие темы разговора, память, история,
очередь задач, функции узлов и уведомления для нескольких клиентов и агентов.

[English / запуск](README.md) · [Android-приложение](https://github.com/weisscorp/android-assistant)

Хаб сам ищет подходящие знания через индекс SQLite FTS5 перед каждым запросом.
В модель попадают выбранные записи, а не вся база. Общие факты доступны в разных
темах, факты конкретной задачи остаются в её теме. Сохранение новых фактов делает
агент через инструмент; отдельная команда «запомни в общей памяти» не обязательна.

Подключения: локальная Ollama, OpenMausBot для кодинга, Codex app-server со штатным входом, официальный
Hermes через MCP, worker-сессии Agent Orchestrator, оригинальный Coucou и
необязательные облачные API. Для OpenAI dot добавлен асинхронный мост через
MCP Events: запрос, выбранный контекст, инструменты и возврат ответа по ID.
Живая подписка требует подключения плагина и проверки.
Режим «Авто» направляет поручения по разработке в отдельный бот OpenMausBot,
продолжает связанный чат и возвращает подтверждённый итог в хаб.
Подключение и разрешения: [кодинг через MausBot](docs/mausbot.md).
Собственная часть хаба — координация, хранение,
поиск, API и адаптеры. Чужие проекты и маскот сохраняют авторство и лицензии.

Это ранняя версия. Android-клиент вынесен в отдельный репозиторий; для сетевого
подключения ему нужен HTTPS-шлюз. В Android есть свой анимированный персонаж;
полный цикл удалённых инструментов телефона пока не реализован. Публикация исходников
не делает работающий хаб доступным из интернета.

Для доступа извне есть отдельные отзываемые ключи клиентов и поддержка HTTPS
через доверенный прокси. API требует `Authorization: Bearer <ключ>`;
отзыв ключа также закрывает его браузерные сессии. Ключи владельца дают полный
доступ; отдельные ключи вебхуков могут только публиковать события.
Порядок выпуска ключей и пример HAProxy: [доступ из интернета](docs/internet-access.md).

Модели могут находить функции подключённых узлов и вызывать их через общий хаб.
Исполнитель подтверждает результат; очередь сама по себе не считается выполнением.
Уже есть сохраняемые таймеры хаба с уведомлениями и отдельный worker компьютера
для чтения времени и информации о системе. Включить его:
`python3 tools/local_stack.py setup --local-node`, затем `start`.
Раздел «Узлы и действия» показывает подключения, вызовы и таймеры.
Для других приложений нужны обработчики их функций.

В разделе «Аудиозаметки» доступны отдельные записи с телефона: WAV-оригинал,
расшифровка, дата и длительность. Файлы хранятся в каталоге состояния
`audio-notes/audio`, тексты — в `audio-notes/notes.sqlite`. Инструмент `audio_notes`
даёт агентам поиск и чтение заметок; текст индексируется в общей памяти.

**Запись для обучения** собирает общий корпус: долгую диктовку с Android и
микрофон/системный звук встреч на macOS. Разметчик large-v3 разрезает записи на
фразы и создаёт предварительные тексты; отдельная задача дообучает T-one.
[Запись, разметка и обучение](docs/speech-dataset.md).
