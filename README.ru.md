# Assistant Hub

Локальный хаб личного ассистента: общие темы разговора, память, история,
очередь задач и уведомления для нескольких клиентов и агентов.

[English / запуск](README.md) · [Android-приложение](https://github.com/weisscorp/android-assistant)

Хаб сам ищет подходящие знания через индекс SQLite FTS5 перед каждым запросом.
В модель попадают выбранные записи, а не вся база. Общие факты доступны в разных
темах, факты конкретной задачи остаются в её теме. Сохранение новых фактов делает
агент через инструмент; отдельная команда «запомни в общей памяти» не обязательна.

Подключения: локальная Ollama, Codex app-server со штатным входом, официальный
Hermes через MCP, worker-сессии Agent Orchestrator, оригинальный Coucou и
необязательные облачные API. Собственная часть хаба — координация, хранение,
поиск, API и адаптеры. Чужие проекты и маскот сохраняют авторство и лицензии.

Это ранняя версия. Android-клиент вынесен в отдельный репозиторий; для сетевого
подключения ему нужен HTTPS-шлюз. Перенос маскота на Android и полный цикл
удалённых инструментов телефона пока не реализованы. Публикация исходников
не делает работающий хаб доступным из интернета.
